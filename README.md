# Item Bro

Учебный backend для площадки с объявлениями об игровых предметах.

Сейчас можно зарегистрироваться, создать объявление и удалить своё.
У пользователя может быть до пяти объявлений во всех играх вместе.
Создание заказов пока в работе.

Проект написан на Java 21 и Spring Boot. Для хранения данных используется
PostgreSQL, для работы с базой — Spring Data JPA и Flyway.
Авторизация настроена через Spring Security и HTTP Basic.

Для локального запуска есть Docker Compose, для проверки API — тесты
с MockMvc и Testcontainers.
