# ItemBro

Учебный backend площадки для торговли игровыми предметами на Java 21 и Spring Boot.

## Возможности

- Регистрация пользователей с хешированием паролей через BCrypt.
- Аутентификация через HTTP Basic и разграничение доступа.
- Создание объявлений: до пяти активных объявлений на пользователя.
- Просмотр активных объявлений по игре с пагинацией.
- Архивирование объявлений владельцем или администратором.
- Создание заказа со списанием средств с внутреннего баланса покупателя.
- Подтверждение заказа покупателем с зачислением средств продавцу.
- Отмена заказа продавцом с возвратом средств покупателю.
- Добавление оценки и отзыва покупателем, ответ продавца.
- Проверка доступа к заказам для участников сделки и администратора.

## Стек

- **Java 21**, **Spring Boot 3**
- **Spring MVC**, **REST API**, **Bean Validation**
- **PostgreSQL**, **Spring Data JPA**, **Hibernate**
- **Spring Security**, **HTTP Basic**, **BCrypt**
- **Flyway**
- **Maven**, **Docker**, **Docker Compose**

## Технические детали

### Структура приложения

Код разделён на контроллеры, сервисы и репозитории.
Для передачи данных используются DTO, для обработки ошибок API —
общий обработчик исключений.

### Работа с данными

- Операции с заказами и балансами выполняются в транзакциях.
- Для денежных значений используется `BigDecimal`.
- Для контроля конкурентных изменений пользователей и заказов
  используется оптимистическая блокировка через `@Version`.
- Схема базы данных версионируется миграциями Flyway.
- Для загрузки связанных данных при просмотре объявлений
  используется `@EntityGraph`.

### Локальное окружение

Подготовлены Dockerfile и Docker Compose для запуска приложения
и PostgreSQL в отдельных контейнерах.

Настроены проверка готовности базы данных и постоянное хранилище
через Docker volume.

## Статус проекта

Проект находится в разработке. Основные сценарии работы
с пользователями, объявлениями и заказами реализованы.

Автоматические тесты в текущей публичной версии пока отсутствуют.
